┌─────────────────────────────────────────────────────────────────────────────────┐
│                    RENDER & DELIVERY LAYER (Django Templates)                     │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│   ┌──────────────────────────────────────────────────────────────────┐         │
│   │             Django Views + Templates (Server-Side Rendering)       │         │
│   │                                                                    │         │
│   │   NO React. NO Next.js. NO separate frontend.                     │         │
│   │   Django receives the request and renders the full HTML page       │         │
│   │   directly using its own template engine.                          │         │
│   │                                                                    │         │
│   │   Request → Django URL router → View → Query DB (via ORM) →       │         │
│   │   Render HTML template → Send finished HTML page to browser        │         │
│   │                                                                    │         │
│   │   URL routes (public site):                                        │         │
│   │   /                      → Homepage (latest + trending + featured) │         │
│   │   /<category>/<slug>/     → Single post page (article+ads+related) │         │
│   │   /category/<slug>/       → Category archive (paginated list)      │         │
│   │   /tag/<slug>/            → Tag archive                            │         │
│   │   /search/?q=             → Search results (DB / Elasticsearch)    │         │
│   │   /author/<slug>/         → Author profile                        │         │
│   │   /sitemap.xml            → Auto-generated sitemap                 │         │
│   │                                                                    │         │
│   │   Templates use: base.html + blocks, {% include %} partials for   │         │
│   │   header, footer, ad slots, subscribe box, related posts.          │         │
│   │                                                                    │         │
│   │   Page fragments cached in Redis ({% cache %} template tag).       │         │
│   └──────────────────────────────────────────────────────────────────┘         │
│                           │                                                      │
│                           ▼                                                      │
│   ┌──────────────────────────────────────────────────────────────────┐         │
│   │                    CDN (CloudFront / Cloudflare)                   │         │
│   │                                                                    │         │
