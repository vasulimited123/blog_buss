┌─────────────────────────────────────────────────────────────┐
│                ADMIN PANEL - BLOG CREATION FLOW               │
└─────────────────────────────────────────────────────────────┘

  STEP 1: Author Logs In
  ─────────────────────────
  │
  ▼
  STEP 2: Create New Post
  ─────────────────────────
  │  - Select Category (e.g., "Marriage Intimacy")
  │  - Add Tags (e.g., "communication", "desire", "couples")
  │  - Write Title
  │  - Auto-generate Slug from title
  │  - Write Body (Rich Text Editor / Markdown)
  │  - Upload Featured Image
  │  - Set Sensitivity Level (General / Mature / Sensitive)
  │  - Add Content Warning (if needed)
  │  - Fill SEO fields (meta title, meta description)
  │  - Add Sources/Citations (URLs)
  │  - Save as DRAFT
  │
  ▼
  STEP 3: SEO Auto-Checker Runs
  ─────────────────────────
  │  Checks:
  │  ✓ Title length (50-60 chars)
  │  ✓ Meta description (150-160 chars)
  │  ✓ Focus keyword in title, first paragraph, headings
  │  ✓ Internal links present
  │  ✓ Image alt tags filled
  │  ✓ Minimum word count (1500+)
  │  ✓ Readability score
  │
  │  Output: SEO Score (e.g., 85/100) + Recommendations
  │
  ▼
  STEP 4: Submit for Review
  ─────────────────────────
  │  Status: DRAFT → IN REVIEW
  │  Action: Notify Medical Reviewer via email
  │
  ▼
  STEP 5: Medical/Expert Review
  ─────────────────────────
  │  Reviewer:
  │  - Checks factual accuracy
  │  - Verifies citations
  │  - Flags misleading claims
  │  - Approves OR Requests Changes (with comments)
  │
  │  If Rejected → Back to STEP 2 (with reviewer comments)
  │  If Approved ↓
  │
  ▼
  STEP 6: Schedule / Publish
  ─────────────────────────
  │  Admin decides:
  │  - Publish Now → Status: PUBLISHED, live immediately
  │  - Schedule → Set future date/time, Celery picks it up
  │
  ▼
  STEP 7: Post-Publish Automation (Celery Tasks)
  ─────────────────────────
  │  Triggered automatically:
  │  1. Optimize & upload images to S3/CDN
  │  2. Regenerate sitemap chunk
  │  3. Invalidate CDN cache
  │  4. Index in Elasticsearch
  │  5. Ping Google (search indexing API)
  │  6. Auto-generate related posts links
  │  7. Send newsletter (if "notify subscribers" was checked)
  │  8. Auto-post to social media (optional)
  │
  ▼
  STEP 8: Live on Website
  ─────────────────────────
     - Available at: yourdomain.com/category/post-slug
     - Appears in category pages, search, sitemap
     - Ads rendered
